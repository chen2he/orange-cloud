## 关于商品名称

App 付费墙的档位按钮直接显示 AGC 返回的 `product.name`，所以名称改了 App 内也会跟着变。当前审核截图里显示的是「Pro 年度 / Pro 终身」，与上表一致。若希望华为收银台与账单里更明确，可改成 `Orange Cloud Pro 年度` / `Orange Cloud Pro 终身版`（19/20 字符，仍在 55 上限内），App 按钮会随之显示长名称。

## 注意

- 价格 ¥128 / ¥298 与 iOS 大陆价对齐（docs/08-monetization.md）。若最终定价改动，付费墙截图上的价格也要重出一版。
- 商品创建后类型与 ID 均不可修改（删除后 ID 也无法复用），保存前核对。
- 在 AGC 开通「应用内支付服务」后，必须重新生成签名 Profile 再打包，否则 `queryEnvironmentStatus` 报 `1001860002`，付费墙整片置灰。
